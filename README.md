# IT Help Desk & Ticketing Management System

A web-based IT Help Desk and Ticketing Management System developed
to manage technical support requests, track ticket status, and
facilitate communication between users, agents, and managers.

## Technologies

- React.js
- ASP.NET Core
- C#
- SQL Server
- Entity Framework Core
- JWT Authentication
- REST API

## Main Features

- User registration and authentication
- Ticket creation and management
- Ticket assignment
- Ticket status tracking
- Agent workflow
- Ticket comments
- Notifications
- Reports and dashboards
- User and admin management

## System Architecture

Frontend: React.js

Backend: ASP.NET Core Web API

Database: SQL Server

Authentication: JWT
